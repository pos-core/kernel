# Order-Item Modifier Snapshot

An order-item modifier snapshot is the order-owned copy of the modifier choices and pricing attached to an order item.

It preserves prompt, choice, and entered-input labels; optional catalog component IDs; quantities; input unit numbers and values; selection sources; effects; nested prompts; price definitions; applied factors; contributions; and the modifier total.

Its IDs are optional so the same shape can represent catalog-backed and manually entered order items without consulting a catalog.
