# Configuration Snapshot

A configuration snapshot is the resolved modifier configuration captured with the pricing facts calculated for it.

It preserves:

- prompt and choice identities
- resolved labels and their label definitions
- explicit and default selection sources
- quantities, effects, and nested modifier branches
- entered choice-input text, input identities, unit numbers, and input labels
- price definitions, price factors, contributions, and the modifier total

Unlike selections, a configuration snapshot contains the human-readable and financial context produced during configuration. Order-item construction translates it into order-owned snapshot types.
